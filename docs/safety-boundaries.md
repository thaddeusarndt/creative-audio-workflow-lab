# Safety Boundaries

This repository is public-safe by design.

## Included

- Synthetic metadata fixtures
- Deterministic planning code
- Generic repurposing prompts
- Markdown reports
- Tests and CI

## Excluded

- Real audio files
- Stems, masters, paid loops, or copyrighted assets
- Private client names or unreleased project details
- Platform credentials or account/session data
- Live distribution, upload, posting, or monetization actions
- Unsupported claims about placements, streams, credits, or commercial performance

## Human-review rule

Reports and prompts are planning aids. Any real release action should be reviewed by a human before publishing, uploading, spending money, contacting people, or touching platform accounts.
